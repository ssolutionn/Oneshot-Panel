Здесь настраивается связь для живого вето и отправки матча в OBS. Сначала выбери, на каком компьютере открыт OBS.

Где открыт OBS?

Что сделать на компьютере с OBS

  1. В OBS открой Сервис → Настройки сервера WebSocket (в английской версии: Tools → WebSocket Server Settings). Включи сервер и аутентификацию.
  2. Нажми «Показать сведения о подключении» / Show Connect Info. Там находятся порт сервера и пароль.
  3. Скопируй ссылку ниже. В OBS открой Док-панели → Пользовательские док-панели браузера, добавь док с именем Oneshot и этой ссылкой.
  4. В появившемся доке укажи адрес WebSocket и пароль из OBS, нажми «Подключить». Затем нажми «Проверить связь» здесь, на сайте.

Адрес и пароль WebSocket вводятся в доке OBS. Код связи уже включён в ссылку.

Код связи

Где найти адрес и пароль

  1. В OBS открой Сервис → Настройки сервера WebSocket (Tools → WebSocket Server Settings).
  2. Включи сервер WebSocket и аутентификацию. Открой «Показать сведения о подключении» / Show Connect Info.
  3. Вставь пароль в поле ниже. Для этого компьютера адрес — ws://127.0.0.1:4455; если в OBS указан другой порт, замени 4455 на него.

Оставь 127.0.0.1, когда сайт и OBS открыты на одном компьютере. Если OBS у обсервера — выбери «На другом компьютере».

WebSocket встроен в OBS Studio 28 и новее. Инструкция OBS ↗

В OBS добавь именно Источники → + → Браузер, вставь ссылку на оверлей и задай 1920 × 1080. Док Oneshot управляет связью; отдельный источник показывает графику в кадре.
