# Изображения карт

Локальные миниатюры Counter-Strike 2: Ancient, Anubis, Cache, Dust2,
Inferno, Mirage, Nuke. Изображения игры — Valve и авторы соответствующих карт.

Источник: [akiver/cs-demo-manager](https://github.com/akiver/cs-demo-manager/tree/main/static/images/maps/cs2/thumbnails).
Сохранено уведомление о лицензии репозитория в LICENSE.txt.
Исходные PNG 600×338 перекодированы в JPEG (качество 84, тот же размер):
2,2 МБ → 0,28 МБ на семь карт, чтобы панель и артефакт грузились быстрее.
Веб-панель загружает их с собственного домена.

## Радары eBot (radar/)

Радары карт в координатах самого eBot (37.230.228.105,
/images/maps/csgo/overview/) — точка хитмапы матча приходит уже в
пикселях ЭТИХ картинок, поэтому фон хитмапы обязан совпадать. Восемь
карт eBot: cbble, cache, dust2, inferno, mirage, nuke, season, train
(у eBot нет anubis, vertigo, ancient, overpass — для них хитмапа
показывается на нашей миниатюре с пометкой «радар приблизительный»).
Изображения игры — Valve и авторы соответствующих карт; скопированы с
нашего сервера eBot, SHA-256 не считался — источник один и тот же.
