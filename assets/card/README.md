# Макет карточек CyberClash

background.png — общий фон 1920×1080, sRGB, подготовлен из утверждённого
пользователем бирюзового макета без игрока, ника и логотипов.
cyberclash-logo.png — отдельный прозрачный логотип из утверждённой карточки.

Ники, эмблемы команд и реальные фотографии HLTV накладываются card.html /
card.js / card.css. В фон не вшиваются данные конкретного игрока.
При ошибке фотографии используется та же композиция без фото:
эмблема команды, её название и крупный ник по центру.
