# Развертывание выделенного сервера CS2 для Oneshot Panel

Эта инструкция описывает пошаговый процесс развертывания выделенного сервера CS2 (Dedicated Server) на Ubuntu 22.04+ с автоматической отправкой игровой телеметрии (логи, киллы, урон, чат) в твою Oneshot Panel.

---

## ⚠️ Важное замечание насчет тикрейта (128 tick)
В **Counter-Strike 2** (на движке Source 2) **нет классического параметра `-tickrate 128`**. Игра перешла на современную субтиковую архитектуру (sub-tick), где сервер обрабатывает действия в точное время события между тиками. Попытка принудительно запустить сервер с `-tick 128` вызовет ошибку конфигурации или будет проигнорирована движком.

---

## Шаг 1. Подготовка сервера (Ubuntu 22.04+)

1. Установи Docker и Docker Compose (если еще не установлены):
   ```bash
   sudo apt update && sudo apt upgrade -y
   sudo apt install -y docker.io docker-compose-v2
   sudo usermod -aG docker $USER
   ```
   *(Перезайди в сессию или выполни `newgrp docker`, чтобы применить права)*.

2. Открой необходимые порты в фаерволе (UFW):
   ```bash
   sudo ufw allow 27015/tcp
   sudo ufw allow 27015/udp
   sudo ufw allow 3000/tcp # Порт Oneshot Panel (если панель на этом же сервере)
   sudo ufw enable
   ```

---

## Шаг 2. Размещение файлов сервера

1. Создай рабочую папку на сервере:
   ```bash
   mkdir -p /opt/oneshot-cs2 && cd /opt/oneshot-cs2
   ```
2. Скопируй туда файлы из нашей папки репозитория `deploy/cs2-server/`:
   - `docker-compose.yml`
   - `oneshot.cfg`

---

## Шаг 3. Настройка интеграции с Oneshot Panel

1. На машине с запущенной Oneshot Panel (`CS2_JOURNAL=1 npm start`) скопируй токен авторизации логов. Он генерируется автоматически и хранится в файле `.cs2-data/token` (или в переменной окружения `CS2_LOG_TOKEN`).
2. Отредактируй файл `oneshot.cfg`:
   ```bash
   nano oneshot.cfg
   ```
   Найди строчку `logaddress_add_http` и укажи реальный IP твоего сервера панели и токен:
   ```cfg
   logaddress_add_http "http://<IP_ПАНЕЛИ>:3000/api/cs2-log?token=<ТОКЕН_ИЗ_ФАЙЛА_TOKEN>"
   ```
3. Укажи надежный RCON-пароль в `docker-compose.yml` (`SRCDS_RCONPW`) и в `oneshot.cfg` (`rcon_password`).

---

## Шаг 4. Запуск сервера

Запусти контейнер через Docker Compose:
```bash
docker compose up -d
```

SteamCMD автоматически скачает и установит CS2 (это может занять 5-15 минут в зависимости от скорости интернета). 

Проверить лог запуска можно командой:
```bash
docker compose logs -f cs2-server
```

---

## Шаг 5. Проверка в Oneshot Panel

1. Открой Oneshot Panel в браузере.
2. Перейди на вкладку **«Сервер»** (она автоматически появится, если панель запущена с `CS2_JOURNAL=1`).
3. Ты увидишь судейский журнал в реальном времени: раунды, фраги, урон (`mp_logdetail 3`), чат и события бомбы.
4. Из панели можно отправлять сообщения в чат сервера через форму RCON (`say`).
