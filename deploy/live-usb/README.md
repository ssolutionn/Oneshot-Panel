# Oneshot LAN Box — Создание загрузочной флешки для выездных турниров

Этот комплект позволяет запустить полноценный турнирный сервер Oneshot Panel вместе с судейским журналом CS2 на любом компьютере за 1 минуту с обычной флешки.

---

## Вариант А. Быстрый старт на готовой Ubuntu Server (Рекомендуется)

1. Установи на ПК чистую **Ubuntu Server 22.04 / 24.04 LTS** (на SSD или прямо с Live USB в режиме permanent install).
2. Вставь любую флешку с этим репозиторием (или скачай скрипт по SSH).
3. Запусти установщик одной командой:
   ```bash
   sudo ./deploy/live-usb/setup-lan-node.sh
   ```
4. Скрипт сам:
   - Установит Node.js v22 и Docker.
   - Скопирует панель в `/opt/oneshot-panel`.
   - Откроет порты в фаерволе.
   - Зарегистрирует systemd-службу автозапуска `oneshot-panel` (панель стартует вместе с компьютером).
   - Выведет локальный IP-адрес для подключения всех организаторов в локальной сети.

---

## Вариант Б. Создание полностью автономного ISO (Ventoy / Rufus)

Если нужно разворачивать систему на «голые» ПК без интернета на площадке:

1. Скачай официальный образ **Ubuntu Server ISO**.
2. Запиши его на флешку через **Ventoy** или **Rufus**.
3. Добавь в корень флешки папку `oneshot-panel` со всеми зависимостями.
4. После загрузки ПК с этой флешки выполни локальный скрипт установки.
