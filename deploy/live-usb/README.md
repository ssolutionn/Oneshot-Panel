# Oneshot LAN Box

Для установки на компьютер используйте новый воспроизводимый комплект в `deploy/oneshot-box/`. Он загружает официальный Ubuntu Server ISO с проверкой SHA-256 и описывает безопасную сборку/установку.

Старый `setup-lan-node.sh` — только пост-установочный сетевой установщик для уже работающей Ubuntu/Debian; он не создаёт ISO или автономную флешку. Не запускайте его как средство подготовки USB. В частности, старый скрипт требует пересмотра перед использованием: работает от root, меняет firewall и обновляет систему.

Создаваемый образ — установочный, не persistent live USB, и не включает CS2. Установка ОС требует сети; автономный стенд потребует заранее собранного локального кэша APT/Node и законно полученных игровых файлов CS2. Игра обычно требует SteamCMD/интернет, а публичный сервер — Steam Game Server Login Token. Не вшивайте секреты.

См. `../oneshot-box/README.md` для шагов и ограничений.
