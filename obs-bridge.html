Подключить телефон по QR

Сначала подключи OBS в полях выше. Затем открой камеру телефона и наведи на этот QR. Сайт подставит код связи; пароль OBS останется на компьютере.

Ссылка даёт управление OBS — отправляй её только своей эфирной команде. Для графики вето скопируй отдельную ссылку на оверлей с телефона.

Где найти адрес и пароль?
  1. Открой Сервис → Настройки сервера WebSocket (Tools → WebSocket Server Settings).
  2. Включи сервер WebSocket и аутентификацию.
  3. Нажми «Показать сведения о подключении» / Show Connect Info. Скопируй оттуда пароль, а порт подставь в адрес выше.
  4. Нажми «Подключить». После подключения панель сможет отправлять камеры и матч. Для вето добавь отдельный источник «Браузер» по ссылке из панели.
