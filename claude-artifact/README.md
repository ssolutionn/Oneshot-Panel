# CyberClash Webcam Desk

Панель обсервера для CyberClash S2: составы и расписание из таблицы турнира → 10 слотов (01–05 / 06–10) → VIEW-ссылки обсерверу, PUSH-ссылки игрокам (Discord markdown) → коллекция сцен OBS в JSON.

Работает как артефакт Claude: страница `claude-artifact/index.html`, шаблон берётся из общего `assets/obs-template.json` (публикуется как `assets/obs-template.json`).

## Откуда берутся данные

- **Таблица турнира** (организатор, «CyberClash Season 2 | Spreadsheet»): составы из листов «Teams (…)», расписание на все дни из «Schedule (Group Stage)» и «Schedule (Playoffs)», счёт, таблицы групп из «Group Stage» для проверки.
- **Рабочая таблица** («CyberClash S2 вебки»): room из листа «Комнаты» и ID потоков из «Все игроки». Если команды там нет, панель придумывает room сама и помечает его как несогласованный.
- Обе таблицы скачиваются через коннектор **Google Drive** того, кто нажал «Обновить составы» (xlsx-экспорт, разбор через SheetJS). Результат сохраняется в хранилище артефакта (`desk/roster`), и вся эфирная команда видит одну версию.
- Нет Google Drive: ⚙ Источник данных → вставить лист целиком (Ctrl+A, Ctrl+C). Понимает блоки команд организатора, «Все игроки», расписание и «Комнаты».
- Расписание сгруппировано по дням, при первом открытии за день выбирается ближайший матч по МСК.

## Что панель проверяет сама

- Буква группы в расписании против таблиц групп в «Group Stage».
- Время в сетке «Group Stage» против расписания.
- Колонки часовых поясов в расписании между собой (GMT / CET / CEST / MSK).
- Названия команд: старые имена `(ex-…)` в расписании и рабочей таблице.
- Составы организатора против рабочей таблицы: лишние и пропавшие игроки, room, повтор ID потока.
- Несогласованные room и пробелы/табы вокруг ников.

## Что изменено относительно версии на chatgpt.site

- Google Sheets gviz-запрос заменён на Google Drive коннектор: прямые запросы к docs.google.com в артефакте заблокированы.
- Скачивание JSON идёт через платформенный `downloads.save` (обычная ссылка `<a download>` в артефакте не работает); если скачивание недоступно, JSON копируется в буфер.
- «Обновить составы» больше не сбрасывает выбранные замены: слоты, которые всё ещё есть в таблице, остаются на местах.
- Одна строка без room больше не роняет загрузку всех составов: строка пропускается и попадает в список «Проверь таблицу».
- Смена источника не стирает уже загруженные составы, пока новая таблица не прочиталась.
- `localStorage` обёрнут в try/catch (в песочнице запись могла бросить исключение и сломать форму настроек).
- Имя файла для команд с кириллицей транслитерируется, а не превращается в `vs.json`.
- Добавлены проверки таблицы: команды с предложенным, но не согласованным room (по листу «Комнаты»), расхождение room между листами, повтор ID потока внутри команды, команды из расписания без состава.
- Тёмная тема.

Логика ссылок и сборки OBS (`viewUrl`, `pushUrl`, `buildObs`, порядок слотов, переименование источников в `CAM NN | команда | ник`) перенесена без изменений.
- Камеры во всех сценах «Игрок 1–10» выравниваются: в шаблоне камеры 6 и 10 повёрнуты на 90°, панель ставит поворот 0°, без обрезки, 1920×1080.
