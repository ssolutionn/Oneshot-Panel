# ТЗ 01: бренд-кит события

Основа всего оформления. Из него красятся оверлей, страница капитанов и карточки. Это не макет
какой-то одной поверхности, а **набор значений и файлов**, которые лежат в `events/<slug>/brand/`.

## 1. Что сдаёт дизайнер

| Файл | Что | Формат |
|---|---|---|
| `logo.svg` | основной логотип, прозрачный фон | SVG (или PNG 2000+ px) |
| `logo-mono.svg` | одноцветная версия (штамп, водяной знак) | SVG |
| `mark.svg` | знак без надписи, квадрат (для маленьких мест, 56–64 px) | SVG |
| `backdrop.jpg` | фоновая картинка/текстура для вето и оверлея | JPG 1920×1080, ≤ 400 КБ, тёмная, без важных деталей по центру |
| `fonts/` | заголовочный и основной шрифты | `.woff2`/`.ttf` + лицензия, кириллица обязательна |
| `tokens` | таблица значений (ниже) | любой текст/таблица |

## 2. Токены (значения, которые заполняет дизайнер)

| Токен | Роль | Пример (CyberClash) |
|---|---|---|
| `accent` | главный акцент, кнопки, подсветка пика | `#00d3ef` |
| `deep` | глубокий фон (градиенты, панели) | `#043746` |
| `black` | самый тёмный фон | `#031b24` |
| `ink` | основной текст | `#ffffff` |
| `muted` | второстепенный текст | `#9fc6cf` |
| `ban` | бан, красный | `#ed1637` |
| `pick` | пик, зелёный | `#2fbf71` |
| `decider` | решающая карта | `#f2c14e` |
| `ct` / `t` | стороны CT и T (читаются как «синий» и «оранжевый», менять осторожно) | `#7fb2f0` / `#f0a95e` |
| `font.display` | заголовки, ники, счётчики | Oswald (узкий, плотный) |
| `font.text` | мелкий текст | системный sans-serif |
| `radius` | скругления панелей | 12–14 px |

Правила:
- `ban` и `pick` должны **отличаться не только цветом** (форма/надпись/значок): часть зрителей не различает красный и зелёный.
- Весь основной текст на фоне — контраст ≥ 4.5:1 (проверяется автоматически при загрузке бренда).
- `ct` и `t` по умолчанию оставляем стандартными: их знают игроки.

## 3. Состояния логотипа

Логотип должен работать: на тёмном фоне (основной случай), на светлом, в **маленьком** размере
(56 px по ширине, на телефоне) и в одноцветном виде. Минимальное поле вокруг — 25% высоты логотипа.

## 4. Приёмка

- Токены заполнены полностью, HEX из 6 знаков.
- Контраст `ink` на `black` и `deep`, `muted` на `black` ≥ 4.5:1 (иначе дизайнер правит).
- Логотип читается при 56 px, нет мелких деталей тоньше 2 px при этом размере.
- Фон не мешает тексту: поверх него в демо кладётся белый текст, он читается.
