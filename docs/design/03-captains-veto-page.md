# ТЗ 03: страница вето капитанов

## 1. Что это и где видна
Страница `veto.html` (стили `veto.css`, дым/прогресс `assets/veto-appearance.js`). Её открывают
капитаны команд **с телефона** в основном, зрители и админ — с чего угодно. Ссылка личная:
`/<событие>_<команда>#k=…`. Только тёмная тема, английский по умолчанию, русский по флагу (EN/RU).
Ширины: от **375 px** до десктопа (брейкпоинты 620 и 900 px).

## 2. Экраны и состояния (нарисовать каждое)

| Экран | Что в нём |
|---|---|
| Шапка | логотип события (92 px, на телефоне 56), eyebrow, заголовок, таймер всего вето, флаги EN/RU |
| Форма админа (создание) | выбор матча, турнир, команды, формат BO1/BO2/BO3/BO5, таймер, кто начинает, транспорт; кнопка «создать» |
| Четыре ссылки | карточки «капитан A», «капитан B», «зрители», «админ»: ссылка + готовое сообщение для Discord, кнопки копирования |
| Ожидание | статус ссылки/комнаты, «связь», кнопка «переподключить» |
| Монетка | анимация броска (2 стороны), кто выбирает порядок |
| Комната: команды | названия, логотипы 52–64 px, «онлайн/нет», пометка «ты» |
| Ход | чей ход, подсказка (что сделать), таймер, кнопки действий |
| Сетка карт | 7 карт: свободная, **бан**, **пик**, пик+сторона (CT/T), решающая, выбранная сейчас |
| Выбор стороны | две кнопки CT / T для соперника пика |
| Итог | список карт по порядку, текст для HLTV (только админ), кнопка копирования |
| Журнал | ходы с временем |
| «Позвать админа» | кнопка и состояние «вызов отправлен» |
| Ошибки и тосты | нет связи, ссылка повреждена, ход не принят |

Для каждого экрана: **375 px и десктоп**, обычное, наведение/фокус, отключённое состояние.

## 3. Данные и тексты
Тексты — в двух языках (`data-i18n`, словарь `WORDS` в `veto.js`); дизайнер присылает макеты
на английском и проверяет, что русские строки (в среднем на 20–30% длиннее) не ломают раскладку.
Названия команд — до 60 символов, кириллица, длинные слова без пробелов. Ник/команда — всегда данные.

## 4. Бренд: токены из 01
Страница использует переменные `--vt-*` в начале `veto.css`: `bg, bg-2, ink, muted, line, panel, accent, accent-ink,
ban, pick, decider, warn, field, coin-a, coin-b, online, offline, ct, t`, шрифт `--vt-display`, фон `veto-backdrop.jpg`.
После внедрения бренда события они берутся из манифеста.

## 5. Анимации
Переезд карточки карты (FLIP), бросок монетки, дым на фоне (WebGL, запасной вариант Canvas2D/без анимации),
прогресс ходов. `prefers-reduced-motion` отключает всё, кроме смены состояния.

## 6. Жёсткие ограничения
- Без сети: шрифты/картинки файлами; CSP не менять; нет inline-скриптов и стилей.
- Тап-зоны ≥ 44×44 px, шрифт кнопок ≥ 14 px; никакой горизонтальной прокрутки на 375 px.
- Фокус клавиатурой виден (капитаны играют и с ноутбука); бан и пик различимы не только цветом.
- Не менять `id` элементов и `data-` атрибуты (на них завязаны логика и тесты).

## 7. Что сдать
Макеты всех экранов в 375 px и десктопе (Figma), токены (01), ассеты, для **L2** — правки `veto.css`/`veto.html` одним коммитом.

## 8. Приёмка
```sh
npm run check && npm test
python3 scripts/qa_veto_site.py --url http://127.0.0.1:3000 --chromium /path/to/chrome   # три отдельных браузера, 375 px
```
Вручную: русский язык, длинная команда, ход на телефоне одним пальцем, монетка, итоговый экран.
