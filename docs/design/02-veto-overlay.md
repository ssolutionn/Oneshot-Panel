# ТЗ 02: оверлей вето для OBS

## 1. Что это и где видна
Графика, которую обсервер ставит в OBS браузерным источником: ходы вето по картам, пока
капитаны банят и пикают. Рисуется на `<canvas>` в `assets/veto-overlay/` (`overlay.html`,
`overlay.css`, `scene.js`, `smoke.js`).

Два вида:
- `layout=full` — полный кадр **1920×1080**, свой фон;
- `layout=strip&crop=1` — плашка **1920×400**, **прозрачный фон**; ставится поверх камер на X=0, Y=680.

Смотрят на стриме (1080p), часто ужатой на экране зрителя до 360–720p.

## 2. Данные (менять нельзя)

```
{ version:1, teams:[A,B], format:'BO1'|'BO2'|'BO3'|'BO5', first:0|1,
  actions:[{map, type:'ban'|'pick', team:0|1, side?:'CT'|'T'}], pending:null|'MapName', stage:'GROUP STAGE' }
```

Модель (`model.js`, `viewModel`) считает всё остальное: `slots[]` — **колонки по ходам** (в BO3 это
BAN BAN PICK PICK BAN BAN DECIDER; всего 7), у каждой `{id:'turn-N', role, name, status, team, sideTeam, side, ownSide, step}`;
`status` ∈ `available | ban | pick | pending | leftover`. Также `teams`, `stage`, `format`, `nextTeam`, `nextType`,
`leftoverLabel` («DECIDER», в BO2 «MAP 02»). Сторона (CT/T) у пика принадлежит **сопернику** выбравшей карту команды.

Карты: Ancient, Anubis, Cache, Dust2, Inferno, Mirage, Nuke (`assets/maps/*.jpg`, MIT; кадрировать можно).
API страницы остаётся: `window.vetoOverlay.{setState(snapshot,{animate}), getState, png, setLayout, stopMotion, description}`,
демо `?preview=1`, `&step=0..6`, `&format=`, `&motion=off`, `&animations=off`.

## 3. Состояния для отрисовки

| Состояние | Что видно |
|---|---|
| Пустая колонка (ход ещё не сделан) | место под карту с названием хода (BAN/PICK) |
| Идёт ход команды X | подсветка колонки и имя ходящей команды |
| Бан | карта обесцвечена, красный крест/штамп, команда |
| Пик, сторона ещё не выбрана | подсветка, рамка, штамп PICK **сразу** |
| Пик + сторона | значок CT/T на карточке (сторона у соперника) |
| Решающая карта | появляется через 1500 мс после последнего хода, метка DECIDER |
| BO1 / BO2 / BO3 / BO5 | своя раскладка колонок |
| Отмена хода | карточка возвращается в «пустую» |
| Нет соединения/ожидание | нейтральная заглушка, не «мёртвая» картинка |

Для каждого состояния — кадр для `full` и для `strip`.

## 4. Анимации

| Событие | Эффект | Время |
|---|---|---|
| Бан | обесцвечивание, крест | 900 мс |
| Пик | подсветка, рамка, штамп PICK (до выбора стороны) | 900 мс |
| Выбор стороны | CT/T на карточке, пик не проигрывается заново | — |
| Решающая карта | появление | 1500 мс задержка |
| Отмена хода | возврат в пустую | 650 мс |
| Повторный снимок (каждые 2,5 с) | **ничего не перезапускает** | — |
| Перезагрузка источника | сразу итоговое состояние, без анимации | — |

`prefers-reduced-motion` — без дыма и переходов; запасной вариант без WebGL (Canvas2D).

## 5. Бренд: токены из 01
`accent, deep, black, ink, muted, ban, pick, decider, ct, t`, `logo`, `backdrop`, `font.display`.
Сейчас они объект `C` в начале `scene.js`; после внедрения бренда события читаются из манифеста.

## 6. Жёсткие ограничения
- Без сети: шрифты и картинки только файлами (`assets/`). CSP `script-src 'self'` не менять, inline-скриптов нет.
- Работает в браузерном источнике OBS (CEF) и в Chrome/Safari; WebGL в OBS может быть выключен.
- Плашка `strip` — **прозрачная** (и PNG-экспорт тоже).
- Текст не мельче 28 px при 1080p; контраст ≥ 4.5:1; бан и пик различимы не только цветом.
- Весь набор ≤ 3 МБ, шрифты только нужные начертания; на слабом ноуте без лагов.
- Не трогать: `model.js`, протокол доставки в `overlay.js` (`veto-state`/`veto-received`), `core.js`, логику вето.

## 8. Приёмка
```sh
npm run check && npm test
python3 scripts/qa_veto_overlay.py   # пиксели, анимации, PNG 1920×1080 и 1920×400 с альфой, reduced-motion
python3 scripts/qa_live.py --url http://127.0.0.1:3000 --chromium /path/to/chrome
```
Вручную: длинное название команды («Very Long Team Name Esports Club»), BO1/BO2/BO3/BO5, перезагрузка источника посреди вето.
