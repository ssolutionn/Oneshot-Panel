# ТЗ 04: карточка игрока

## 1. Что это и где видна
Страница **1920×1080**, которую OBS показывает в браузерном источнике `CARD NN | Команда | Ник`
**под камерой игрока**: пока видео нет (игрок не подключился, пропала связь) в кадре видна карточка,
при видео она закрыта камерой. Для CyberClash это `card.html` + `card.css` + `card.js`;
для событий без своего сайта (ЛАН) — одна самодостаточная страница `eventCardHtml()` в `lan-event.js`
(в OBS уходит как `data:`-страница, все картинки внутри).

**Важно про масштаб.** Карточка вписывается в рамку камеры целиком с сохранением пропорций
(`OBS_BOUNDS_SCALE_INNER`). Рамка по умолчанию 1320×1008, значит карточка в эфире показывается
**в ~69% от 1920×1080** (≈1320×743, по центру). В сцене «Матрица» — ещё меньше (плитка ≈ 480×270).
**Все размеры шрифтов проверять при 69% и при 25%.**

## 2. Данные

```
{ team: 'Название команды', nick: 'Ник', photo: <прозрачный PNG/WebP, до ~110 КБ> | нет, logo: <логотип команды> | нет }
```
- Фото: человек **по пояс/в рост, прозрачный фон**, обрезан по контуру; соотношение сторон
  разное (стоячий, сидящий). У HLTV-фото ≈ 400×417, у фото с iPhone после обработки до 800 px по высоте.
- Логотип команды: квадратный/любой, прозрачный фон.
- Название команды — до 60 символов; ник — до 40, может быть длинным, с кириллицей и символами.

## 3. Состояния (нарисовать все)

| Состояние | Что видно |
|---|---|
| Фото + логотип команды | портрет по центру, имя команды с маленьким логотипом, ник крупно |
| Фото без логотипа | то же без значка |
| Без фото + логотип | крупная эмблема команды по центру, имя, ник |
| Без фото и без логотипа | только имя команды и ник, фирменный фон |
| Длинный ник | ник уменьшается/переносится, не вылезает |
| Длинное название команды | перенос по словам, не перекрывает ник |
| Загрузка | не пустой кадр: фон события виден всегда |

## 4. Что есть в кадре сейчас (ориентир, не обязательство)
Фон (градиент + текстура), логотип события справа сверху (≈290×147), портрет по центру (высота до 1000–1150 px),
затемнение снизу, команда (46 px, заглавные, разрядка), ник (224 px без фото / 160 px с фото), акцентная черта.

## 5. Бренд: токены из 01
`accent, deep, black, ink, muted`, `font.display`, `logo`, `backdrop`; для ЛАН-карточки токены задаются в самой панели
(три цвета: акцент, фон, тёмный).

## 6. Жёсткие ограничения
- **Без сети**: все картинки внутри страницы или рядом файлами; шрифты — системные или встроенные в страницу.
- Фото рисуется поверх фона с мягкой тенью; не обрезать голову при любом соотношении сторон.
- Контраст ника и команды к фону ≥ 4.5:1 как с фото, так и без него.
- В карточку для OBS нельзя добавлять скрипты, кроме подгонки размера ника.
- Размер страницы с фото ≤ ~130 КБ (идёт в OBS по каналу данных частями).

## 7. Что сдать
Макеты 1920×1080 для всех состояний (раздел 3), значения токенов, ассеты фона. Для **L2** — `card.css`/`card.html`
(для CyberClash) и обновлённый `eventCardHtml()` (для ЛАН) в одном коммите.

## 8. Приёмка
```sh
npm test                                 # test/lan-event.test.js: экранирование, размер, состояния
python3 scripts/qa_player_cards.py ...   # CyberClash: все карточки каталога
python3 scripts/qa_lan.py --url ...      # ЛАН: импорт, превью, JSON, док
```
Вручную: карточка в сцене «Игрок N» (≈69%) и в «Матрице» (плитка), ник «Whatever_LongNick123», команда из 40 символов.
