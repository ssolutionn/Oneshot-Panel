# Ревью ONESHOT Panel

Проверенная база: `e572d1a1a7fc90696072b915773abd1e8949fc89`, ветка `claude/gracious-sagan-apztcc`.
Задача: ревью проекта и редизайн по предоставленному изображению.
Замечания ниже относятся к исходной базе; состояние после редизайна указано отдельно.

## Замечания

### 1. P1 — Claude-версия зависит от отсутствующего каталога assets

Место: [build_oneshot_artifact.py:611](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/claude-artifact/build_oneshot_artifact.py#L611).

Сборщик заменяет запрос шаблона на `fetch('assets/obs-template.json')`,
но встраивает только логотипы. При открытии
`/claude-artifact/oneshot-panel.html` браузер ищет
`/claude-artifact/assets/obs-template.json`; такого файла в репозитории нет.
В отдельно переданном HTML файла также нет. Загрузка шаблона падает,
кнопка экспорта остаётся выключенной даже при корректных составах.

Исправлено в редизайне: сборщик встраивает исходный OBS-шаблон и изображения
карт в Claude-версию. Веб-версия продолжает загружать локальные файлы.
Оригинальный `assets/obs-template.json` не изменён.

### 2. P2 — изменение положения строки расписания сбрасывает вето

Места: [core.js:58](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/core.js#L58),
[app.js:260](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/app.js#L260),
[app.js:418](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/app.js#L418).

Ключ матча содержит индекс исходной строки. Если перед выбранным матчем
вставить строку или поменять порядок расписания, тот же матч получает
другой ключ. После обновления `render()` очищает `state.matchKey`,
а `renderVeto()` считает это сменой матча и удаляет завершённые ходы.
Затем `persist()` сохраняет уже очищенное вето.

Диагностическое воспроизведение: один матч до вставки заголовка имеет ключ
`[0,"16:00","A","B","B"]`, после — `[1,"16:00","A","B","B"]`.
Содержимое матча не менялось.

Рекомендация: использовать устойчивый идентификатор матча из таблицы
или стабильную идентичность с различением повторных встреч; предусмотреть
миграцию сохранённого ключа. Не исправлялось в визуальном изменении:
это отдельное изменение хранения состояния, требующее регрессионного сценария.

### 3. P2 — экспорт принимает шаблон без обязательной сцены «Матрица»

Место: [core.js:241](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/core.js#L241).

Проверяются десять сцен игроков, но цикл матрицы использует optional chaining
и пустой массив при отсутствии сцены. Удаление «Матрицы» из копии шаблона
не приводит к ошибке: `buildObs()` возвращает коллекцию без неё,
с оставшимися ссылками на неё в `scene_order` и `current_scene`.

Диагностическое воспроизведение на оригинальном шаблоне подтвердило:
экспорт успешен, сцены «Матрица» нет, запись в `scene_order` осталась.

Рекомендация: проверять существование сцены «Матрица», тип scene,
ссылки на все десять сцен и корректность ссылок коллекции до экспорта.
Не исправлялось: оригинальная логика сборки OBS сохранена в рамках редизайна.

### 4. P2 — выбор игрока уничтожает клавиатурный фокус

Места: [app.js:267](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/app.js#L267),
[app.js:327](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/app.js#L327).

Изменение select вызывает `render()`, который заменяет весь `teamGrid`.
Активный select удаляется; следующий Tab начинает перемещение с потерянной
позиции. Это затрудняет последовательную настройку десяти слотов без мыши.

Исправлено в редизайне: перед перерисовкой сохраняется идентичность
активного выбора команды/игрока, после восстанавливается фокус без прокрутки.
Новые поля состояния и новые обязательные DOM-привязки не добавлены.

### 5. P3 — вето не имеет изображений карт

Место: [app.js:464](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/app.js#L464), каталог `assets/`.

Все семь путей изображений отсутствуют в исходном дереве.
Удаление битых img предотвращает значки ошибок, но не даёт вид из референса.

Исправлено: добавлены семь локальных PNG; источники и лицензия указаны
в `assets/maps/README.md` и `assets/maps/LICENSE.txt`.
Пул, порядок и правила вето не изменены.

### 6. P3 — сборщик Claude-версии зависит от точного форматирования CSS

Место: [build_oneshot_artifact.py:44](https://github.com/ssolutionn/Oneshot-Panel/blob/e572d1a1a7fc90696072b915773abd1e8949fc89/claude-artifact/build_oneshot_artifact.py#L44).

Несколько `replace_once` требуют дословного совпадения минифицированных
CSS-правил. Изменение отступов или нового оформления шапки ломает сборку,
хотя веб-версия остаётся исправной.

Исправлено: safe-area стили добавляются отдельно для обёртки артефакта.
Проверки точечных замен JS и HTML сохранены: несовпавший якорь
по-прежнему останавливает сборку.

## Проверки и границы уверенности

- Среда Codex при работе не предоставила терминал и браузер.
- Чистая логика дополнительно проверена в доступном V8: 19 из 20
  адаптированных core-сценариев прошли; один не исполнялся из-за отсутствия
  глобального `URL`. Это не запуск `npm test`.
- Проверены сохранность всех прежних HTML id, отсутствие дубликатов,
  синтаксический разбор изменённых JS и сформированного скрипта артефакта.
- Полноценная проверка вынесена в GitHub Actions:
  `npm run check && npm test`, пересборка артефакта с проверкой
  воспроизводимости, 22 браузерных сценария на синтетических Sheets.
  Актуальные результаты — в Checks соответствующего PR/коммита.
- Браузерные сценарии не доказывают доступность живой Google Sheets
  и фактическое отображение коллекции внутри OBS.
- Визуальное соответствие и удобство требуют просмотра скриншотов/панели.
  При ширине 375px отсутствие прокрутки проверяет браузерный сценарий.
