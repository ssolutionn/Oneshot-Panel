# CyberClash Webcam Desk

Панель обсервера для CyberClash S2: составы из рабочей таблицы → 10 слотов (01–05 / 06–10) → VIEW-ссылки обсерверу, PUSH-ссылки игрокам (Discord markdown) → коллекция сцен OBS в JSON.

Работает как артефакт Claude (`index.html` + `assets/obs-template.json`).

## Откуда берутся данные

- Таблица «CyberClash S2 вебки» скачивается через коннектор **Google Drive** того, кто нажал «Обновить составы» (xlsx-экспорт, разбор через SheetJS).
- Листы находятся сами: «Все игроки» (составы), «Матчи DD.MM» (расписание, берётся лист на сегодня по МСК), «Комнаты» (статус room).
- Последние составы сохраняются в хранилище артефакта (`desk/roster`), поэтому вся эфирная команда видит одну версию без своего доступа к Drive.
- Нет Google Drive: ⚙ Источник данных → вставить лист «Все игроки» (Ctrl+A, Ctrl+C) прямо в панель. Так же вставляются «Матчи» и «Комнаты».

## Что изменено относительно версии на chatgpt.site

- Google Sheets gviz-запрос заменён на Google Drive коннектор: прямые запросы к docs.google.com в артефакте заблокированы.
- Скачивание JSON идёт через платформенный `downloads.save` (обычная ссылка `<a download>` в артефакте не работает); если скачивание недоступно, JSON копируется в буфер.
- «Обновить составы» больше не сбрасывает выбранные замены: слоты, которые всё ещё есть в таблице, остаются на местах.
- Одна строка без room больше не роняет загрузку всех составов: строка пропускается и попадает в список «Проверь таблицу».
- Смена источника не стирает уже загруженные составы, пока новая таблица не прочиталась.
- `localStorage` обёрнут в try/catch (в песочнице запись могла бросить исключение и сломать форму настроек).
- Имя файла для команд с кириллицей транслитерируется, а не превращается в `vs.json`.
- Добавлены проверки таблицы: команды с предложенным, но не согласованным room (по листу «Комнаты»), расхождение room между листами, повтор ID потока внутри команды, команды из расписания без состава.
- Тёмная тема.

Логика ссылок и сборки OBS (`viewUrl`, `pushUrl`, `buildObs`, порядок слотов, переименование источников в `CAM NN | команда | ник`) перенесена без изменений.
