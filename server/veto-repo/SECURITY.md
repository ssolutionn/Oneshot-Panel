# Безопасность

Сайт вето капитанов CyberClash — сгенерированная копия части репозитория
`ssolutionn/Oneshot-Panel`; модель угроз и известные ограничения описаны в его
`SECURITY.md`.

Об уязвимости сообщайте не через публичный issue, а через **Security → Report a
vulnerability** в этом репозитории или личным сообщением владельцу (`ssolutionn`).
