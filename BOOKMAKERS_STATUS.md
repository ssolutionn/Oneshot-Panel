## Что означает статус

- «—» — источник успешно прочитан, матч в полученной части линии не найден.
- «?» — источник ещё проверяется, недоступен, ответ неполный или парсер не подключён.
- «Данные устарели» — показан последний успешный ответ этого окна; свежие коэффициенты не подтверждены.
- «Только прематч» — данный адаптер не проверяет текущие лайв-матчи.
- Одиннадцать адаптеров не означают постоянную доступность всех одиннадцати. Ошибка отдельного источника сохраняет старый результат с отметкой времени.

## Ограничения и безопасность

API только GET, только фиксированные источники. Параметр id не превращается
в URL; редиректы не выполняются. Общий бюджет зеркал 24 секунды, один
источник не задерживает таблицу остальных. Ответы HTTP ограничены 16 МиБ,
WebSocket — размером пакета, суммарным потоком и временем подключения.
Короткий кэш в памяти объединяет одновременные запросы.

Нет входа в аккаунты букмекеров, чужих cookies, паролей, ключей, обхода капч
или подделки подписанных заголовков. На сайте не появился серверный ввод
на запись. Названия выводятся текстом, ссылки ограничены доменами контор,
CSV защищён от формул из внешних строк. Данные недели хранятся только
в браузере оператора. История и CSV основной ветки сохранены.

Для Winline HTTP Upgrade реализован под Cloudflare. В средах без
серверного WebSocket Upgrade этот источник вернёт недоступность; остальные
адаптеры используют обычный HTTP. npm-зависимости не добавлены.
